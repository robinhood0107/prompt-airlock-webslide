Prompt Airlock 중간 발표

  • 공공기관 직원이 외부 LLM 서비스를 쓸 때, 질문에 들어 있는 개인정보가 밖으로 나가지 않게 막는 프로그램입니다.
  • 10월에는 질문을 보내고 답을 받기까지 실제로 동작하는 첫 버전을 만들었습니다.

문제

"한빛시청 김민준 주무관에게 010-2345-6789 로 회의 일정을 알려 주는 안내문을 써 줘"

  • 이런 질문을 그대로 보내면 이름, 소속, 전화번호가 외부 회사 서버로 넘어갑니다.
  • 그렇다고 개인정보를 지우면 누구에게 연락하라는 건지 알 수 없어 쓸모 있는 답을 받기 어렵습니다.
  • 국가정보원 보안 가이드라인도 외부로 보내는 질문과 받은 답에서 민감한 정보를 걸러 내라고 요구합니다.

해결 방향

  • 개인정보를 지우지 않고, 보내기 전에 가짜 이름표(가명)로 바꿉니다.
  • 예를 들어 "김민준"은 "⟦PERSON_PYZHWD8MSY⟧" 같은 의미 없는 글자로 바뀝니다.
  • 외부 LLM 은 가명만 보고 답을 만들고, 답이 돌아오면 가명을 다시 원래 값으로 바꿔 줍니다.
  • 개인정보는 전화번호 같은 모양 규칙과, 문장 속 사람·기관 이름을 알아보는 모델(NER)로 찾습니다.
  • 가명과 원래 값의 짝은 기관 안에서만 보관하므로, 밖에서는 원래 값을 알 수 없습니다.

가명 보관 프로그램(Vault)

  • 가명과 원래 값의 짝을 보관하는 작은 프로그램입니다. 게이트웨이와 따로 실행해서, 게이트웨이에 문제가 생겨도 짝 목록은 다른 곳에 있게 했습니다.
  • Rust 로 만들었습니다. Rust 는 메모리를 잘못 다루는 실수를 컴파일할 때 잡아 주는 언어라, 민감한 값을 다루는 부분에 썼습니다.
  • 게이트웨이와는 같은 컴퓨터 안에서만 쓰는 통로로 대화하고, 프로그램을 실행한 사용자만 접근할 수 있습니다. 네트워크 포트는 열지 않습니다.
  • 가명은 운영체제가 만드는 난수로 질문마다 새로 만들고, 질문이 끝나면 짝을 지웁니다. 지운 자리는 0 으로 덮어써서 메모리에 원래 값이 남지 않게 했습니다.

이미 있는 도구

  • LiteLLM 은 여러 LLM 회사를 같은 방식으로 쓸 수 있게 이어 주는 중간 서버입니다. 질문을 보내기 전과 답을 받은 뒤에 검사 프로그램을 붙일 수 있습니다.
  • Presidio 는 Microsoft 가 만든 개인정보 검사 도구로, 개인정보를 찾는 부분과 다른 글자로 바꾸는 부분으로 나뉩니다. LiteLLM 에 검사 프로그램으로 붙여 쓸 수 있습니다.
  • 둘 다 기본 언어가 영어라서, 주민등록번호 같은 한국 형식은 사용자가 직접 추가해야 합니다.

처리 순서

모든 검사를 통과한 질문만 밖으로 나갑니다.

중간에 하나라도 실패하면 그 자리에서 멈춥니다.

들어올 때

  1. 등록된 앱인지 확인
  2. 기밀 문서인지 확인

개인정보
가리기

  1. 개인정보 찾기
  2. 가명으로 바꾸기
  3. 남은 개인정보 다시 찾기

보내고
받을 때

  1. 외부 LLM 으로 보내기
  2. 받은 답 검사
  3. 원래 값으로 되돌리기

가명이 오가는 과정

  • 밖으로 나가는 질문에는 가명만 들어갑니다.
  • 답이 오면 이번 질문에서 만든 가명만 원래 값으로 되돌립니다.
  • 가명이 한 글자라도 바뀌어 돌아오면 되돌리지 않습니다. 다른 사람의 정보가 잘못 들어가는 일을 막기 위해서입니다.
  • 답의 링크 주소 안에 가명이 들어 있으면 답 전체를 막습니다. 링크를 누르는 순간 원래 값이 다른 사이트로 넘어갈 수 있기 때문입니다.

실수와 고장에도 새지 않게

  • 질문은 정해진 검사를 순서대로 다 거쳐야만 밖으로 보낼 수 있게 만들었습니다.
  • 개발자가 실수로 검사를 빼먹은 코드는 프로그램이 아예 만들어지지 않습니다.
  • 개인정보를 찾는 모델이나 가명 보관 프로그램이 멈추면, 질문을 보내지 않고 거절합니다.

시연

  1. 기밀 문서 질문은 바로 막습니다.
  2. 주민등록번호와 카드번호는 막고, 어떤 종류였는지만 알려 줍니다.
  3. 이름, 전화번호, 이메일은 가명으로 나갔다가 원래 값으로 돌아옵니다.
  4. LLM 이 가명을 링크에 넣으면 답을 막습니다.
  5. 다른 글자로 숨긴 주민등록번호도 찾아서 막습니다.
  6. LLM 이 가명을 바꿔 오면 되돌리지 않습니다.

실제로 프로그램을 실행해 질문 6개를 보낸 기록입니다. 왼쪽은 보낸 질문과 받은 결과, 오른쪽은 외부 LLM 쪽이 실제로 받은 내용입니다.

0건시연 6개에서 원래 값이 밖으로 나간 횟수입니다.

초당 115개질문 8개를 동시에 계속 보내도 오류 없이 처리했습니다.
